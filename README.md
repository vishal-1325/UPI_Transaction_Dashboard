# 📊 
UPI Transaction Dashboard (Excel)

An interactive Excel dashboard built to analyze PhonePe UPI transactions using Pivot Tables, Pivot Charts, Slicers, and Excel analytics features. The dashboard provides insights into transaction volume, payment amount, success rate, fraud detection, banking trends, and customer transaction behavior.

Dataset: This project uses a dummy/simulated PhonePe transaction dataset created for learning and portfolio purposes. It does not contain any real or confidential customer data.

## 🎯 Project Objective

The objective of this project is to analyze UPI transaction data and create an interactive dashboard that helps users explore payment trends, transaction performance, and business insights through dynamic filters and visualizations.

---

## 📌 Features

- ✅ Interactive Slicers
- ✅ Dynamic Dashboard
- ✅ Daily Transaction Trend
- ✅ State-wise Transaction Analysis
- ✅ Bank-wise Transaction Analysis
- ✅ UPI App-wise Analysis
- ✅ Transaction Status Analysis
- ✅ Transaction Type Analysis
- ✅ Hourly Transaction Analysis
- ✅ Day & Hour Heatmap
- ✅ Success Rate Monitoring
- ✅ Cashback Analysis
- ✅ Suspected Fraud Tracking

## 📊 Dashboard Insights

- Monitors transaction trends over time.
- Identifies top-performing UPI applications.
- Compares transaction performance across Indian states.
- Tracks payment status (Success, Failed, Pending, Refunded).
- Identifies high-volume banks.
- Shows transaction distribution by payment type.
- Detects suspected fraud transactions.
- Analyzes transaction activity by hour and weekday.
